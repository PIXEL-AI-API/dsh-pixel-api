# dsh-pixel-api

DeepSeek Harness 插件：用 [PIXEL](https://api.ai-pixel.online) 主站账号登录后，把账号可用的分组与模型挂载成模型来源，对话直接扣主站钱包余额，**不需要创建 API Key**。

## 安装

在 DeepSeek Harness 的 **插件 → 添加插件** 里填 GitHub 仓库地址：

```
https://github.com/PIXEL-AI-API/dsh-pixel-api
```

需要固定某个版本时在末尾加提交号或标签，例如：

```
https://github.com/PIXEL-AI-API/dsh-pixel-api#v0.1.0
```

也可以填本地目录路径，或把仓库克隆到本地后填该目录。

## 使用

1. 打开 **设置 → PIXEL API**，输入主站用户名和密码登录（账号启用两步验证时，会要求输入一次 TOTP 验证码）。
2. 登录成功后卡片显示账号、用户分组、钱包余额、已用金额与请求次数；点「刷新」可立即更新，「充值」打开主站钱包页。
3. 打开任意会话，点输入框右下角的模型名，在左栏选分组、右栏选模型即可对话。

对话按主站该分组当前的计费倍率扣主站钱包余额。

## 模型菜单变成左右两栏

登录成功后，输入框的模型菜单会替换为：

- **左栏**：模型分组，每行显示分组名、计费倍率（`×0.25`，低于 1 绿色、高于 1 橙色）、分组 ID（`ID: xxx`）；顶部搜索框可按分组名、分组 ID 或模型名搜索。
- **右栏**：该分组下的模型，当前选中的打勾；底部一行是推理等级（该模型支持时）。

键盘：`↑`/`↓` 选模型，`Alt` + `←`/`→` 切换分组，`Enter` 确认，`Esc` 关闭。

这个菜单替换的是 Harness 的通用模型菜单，因此对 **所有** 模型来源（DeepSeek、其他第三方提供方）同样生效，不只是 PIXEL。

## 安全与隐私

- **密码只用一次**：登录成功后立即从本机凭据库删除，不会以明文留在磁盘上。本机只保留主站签发的登录会话令牌（相当于浏览器里的登录状态）。
- **会话有效期约 30 天**，会自动续期；失效后需要重新输入一次密码。
- **点「退出登录」会通知主站注销该会话**，不是只删本地记录。
- **所有发往主站的请求拒绝重定向**，避免带凭据的请求被转发到其他地址。
- 发往主站的数据：分组与模型列表、账号余额等账户信息；对话内容经主站转发给所选模型。插件不向其他任何域名发请求，也不会上传你的本地文件或会话记录。
- 调试日志默认关闭。在插件配置里设 `debug: true`（或设环境变量 `PIXEL_API_DEBUG=1`）后，会在 `~/.dsh/pixel-api/debug.log` 记录执行步骤与 HTTP 状态码，**不含令牌、Cookie、密码或响应内容**，文件超过 512 KB 自动换新。

## 限制

- 只支持文本与工具调用；**不支持图片输入**，带图片的消息会直接报错。
- 分组倍率与模型列表在登录时拉取；主站改了倍率后，点一次「刷新」或重新登录即可同步。
- 依赖 Harness `0.2.2-rc.3` 以上、`0.3.0` 以下版本（见 `package.json` 的 `engines.dsh`）。

## 停用

在 **插件** 页关闭本插件后，PIXEL 的模型来源立即从模型选择器移除。已有会话记录不受影响；要彻底清除登录状态，请先在设置页点「退出登录」。
